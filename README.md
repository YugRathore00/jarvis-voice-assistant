# Jarvis Voice Assistant 🎙️

A Python-based virtual assistant inspired by JARVIS that uses speech recognition, text-to-speech, and generative AI to execute commands, play music, fetch news, and answer queries.

## Features
* **Wake-word Activation:** Listens for the wake word "Jarvis".
* **Web Automation:** Opens popular websites like Google, YouTube, Facebook, and LinkedIn.
* **Music Streaming:** Plays songs via custom links defined in `musicLibrary.py`.
* **News Updates:** Fetches top headlines using the NewsAPI.
* **AI Integration:** Powered by advanced language models to handle conversational queries and respond using text-to-speech (`gTTS` and `pygame`).
